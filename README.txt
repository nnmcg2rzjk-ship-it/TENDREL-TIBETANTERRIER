# TENDREL TIBETAN TERRIER — GitHub Pages用サイト

Wixの画面録画をもとに、淡いブルー／アイボリーを基調とした構成で作った静的サイトです。

## ファイル
- index.html : トップ
- about.html : チベタンテリアについて
- dogs.html : 犬たち
- puppies.html : 仔犬を迎える条件
- contact.html : お問い合わせ
- style.css : デザイン
- script.js : メニュー
- images/ : 写真

## 写真の入れ替え
`images` フォルダの画像を同じファイル名の新しい写真に置き換えるだけで変更できます。
今入っている画像は、提供されたWix画面録画から作った「仮画像」です。公開前に元の写真へ差し替えてください。

## GitHub Pages
GitHubのリポジトリにこのフォルダ内のファイルをアップロードし、
Settings → Pages → Deploy from a branch → main / root
を選択します。

ページを追加するときは、既存ページをコピーして `newpage.html` を作り、
ヘッダーのナビゲーションにリンクを1行追加すればOKです。

## 重要
文章・連絡先・SNSリンク・写真などは公開前に実際の内容へ差し替えてください。
